# SauceDemo Automation Testing

Automated testing of https://www.saucedemo.com using Java, Selenium WebDriver and TestNG.

## Tools
Java, Selenium WebDriver, TestNG, Maven, Apache POI, Eclipse, Git

## Features
- Page Object Model with Page Factory
- Data-driven testing using Excel (Apache POI)
- Configuration using a properties file
- Manual test cases in docs/SauceDemo_TestCases.xlsx

## Scenarios Covered
Valid login, invalid login, locked-out user, add to cart,
checkout, logout

## How to Run
1. Clone the project and import it as a Maven project
2. Run testng.xml as a TestNG Suite
